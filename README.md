# sysloghub
Free Server for Collecting Syslog &amp; SNMP Traps

We didn’t need a server with complex or numerous features; we simply needed one that could collect syslog and SNMP trap logs. 

We needed a syslog server that could be accessed from anywhere via the web and had no restrictions on the number of connected systems or log collection.

This solution should be suitable for anyone in need of such a simple syslog solution.

It is not a solution like a SIEM that processes large volumes of syslog data to perform correlation analysis.

It is simply a solution for centrally collecting syslogs from network switches.

Please keep in mind that this solution is not suitable for security devices—such as firewalls—that generate vast amounts of logs, or for web server systems.

I’m currently working on the code whenever I have free time.

I’m also checking for bugs and testing to ensure it runs properly.

I can’t guarantee when the solution will be uploaded to GitHub.

If you decide to use this solution in the future, I recommend using it only on a private network or intranet whenever possible.

This is because I cannot fully address all security vulnerabilities.

This solution could potentially become a security hole and serve as an entry point for hackers.

I’m sure you aren’t expecting much anyway, but just in case, please don’t get your hopes up—it might just be all show and no substance.
